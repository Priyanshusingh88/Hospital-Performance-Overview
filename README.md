# Hospital Performance Overview

## 1. Project Name
**Hospital Performance Overview – Power BI Dashboard**

## 2. Short Description / Purpose
This project focuses on analyzing hospital performance using 55,500 patient records. The interactive Power BI dashboard provides insights into patient admissions, age groups, length of stay, billing, revenue, insurance providers, and medications.

The main purpose is to help understand hospital operations and support data-driven decision-making.

## 3. Tech Stack
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV

## 4. Data Source
- Dataset: Healthcare Dataset (Kaggle)
- Total Records: 55,500
- Data Type: Hospital patient and admission records
- Format: CSV
- source:https://www.kaggle.com/datasets/prasad22/healthcare-dataset?utm_source=chatgpt.com

*Note: The dataset appears to contain synthetic healthcare data.*

## 5. Features / Highlights

- **Data Cleaning:** Removed 108 negative billing records and 532 duplicate records using Power Query.
- **Data Transformation:** Created new columns such as Age Group and Length of Stay.
- **KPI Development:** Created 6 key performance indicators using DAX.
- **Interactive Dashboard:** Designed a one-page dashboard with 7 charts and 4 slicers.
- **Patient Analysis:** Analyzed patient demographics, age groups, and admissions.
- **Billing & Revenue Analysis:** Evaluated billing amounts and revenue distribution.
- **Insurance Analysis:** Compared revenue contributions across insurance providers.
- **Business Insights:** Answered 9 key business questions to understand hospital performance.

### Key Insights
- Patients aged 65+ represent the largest age group (29.3%).
- Almost half of the hospital stays last 16 days or more.
- Revenue is distributed almost equally across five insurance providers.
- July and August are the busiest admission months.
